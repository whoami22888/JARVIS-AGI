# Network Ninja Master 0.2.1 — Patch ISO and Ventoy Verification

**Release status:** `VALIDATED_SOFTWARE_AND_BIOS_VM_BASELINE`

Network Ninja Master 0.2.1 is the patch release containing the agent-backend security and memory-audit remediations. A clean Debian Bookworm live ISO was built from the hardened source, checked by SHA-256, inspected at the ISO and SquashFS layers, and started under BIOS-mode QEMU. The embedded binary was extracted from the live filesystem and exercised as a loopback service; its write-token protection denied an uncredentialed agent write and accepted a request with the runtime-issued token.

> The verified result is a Ventoy-ready ISO plus a validated persistence mapping. It is not a claim that a physical Ventoy USB, persistence across a physical reboot, UEFI firmware, Secure Boot, or arbitrary target hardware has passed.

## Ventoy deployment layout

Copy the following files to the corresponding locations on an already-installed Ventoy USB data partition. Verify the ISO checksum before use.

| Ventoy data-partition path | Source artifact |
|---|---|
| `/iso/network-ninja-master-0.2.1-linux-amd64.iso` | `dist/network-ninja-master-0.2.1-linux-amd64.iso` |
| `/ventoy/ventoy.json` | `build/ventoy/ventoy.json` |
| `/persistence/network-ninja-master-persistence.dat` | Generated by `scripts/create-persistence.sh --output … --size-mb …` |

The configuration maps the exact 0.2.1 ISO path to the persistence backend and enables automatic selection. The generated backend is an ext4 image labeled `persistence` and contains the Debian Live rule `/ union`.

## Remaining release gates

Physical boot testing should use an authorized disposable USB, the target’s documented BIOS or UEFI mode, and a post-reboot persistence check. Do not label the ISO as UEFI-validated, Secure-Boot-compatible, or physically Ventoy-tested until those specific tests produce evidence.
